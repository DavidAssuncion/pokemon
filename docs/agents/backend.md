## Buenas prácticas

* Aplicar SOLID.
* Mantener controladores ligeros.
* Utilizar Services para lógica compleja.
* Utilizar Form Requests.
* Evitar duplicación.
* Crear código legible.
* Mantener compatibilidad con la arquitectura existente.
* Añadir tests cuando corresponda.
